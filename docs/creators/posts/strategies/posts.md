# Photos.earnings (Expanded Attribution Economy Model)

## Philosophy

Every participant that adds measurable value to the ecosystem can earn:

- creation value
- hosting value
- distribution value
- discovery value
- derivative value
- conversation value
- curation value
- localization value
- collaboration value
- conversion value
- retention value

---

# XV. Strategic Principles

1. Original creators should continue earning downstream.

2. Distributors should earn for audience acquisition.

3. Curators should earn for discovery labor.

4. Editors/translators should earn for transformation labor.

5. Hosts should earn for meaningful discussions.

6. High-quality engagement should outweigh raw volume.

7. Long-term value should outweigh short-term virality.

8. Attribution must remain explainable and auditable.

9. Recursive royalties must be capped.

10. Platform health must override engagement farming.
